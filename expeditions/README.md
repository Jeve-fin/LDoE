# Settlement Expeditions

Экспедиции Поселения.

Структура:
- `ghost-town/`
- `destroyed-station/`
- `old-train-station/`

Каждый уровень — отдельная запись либо строка в проверенной таблице.

Обязательно хранить:
- рекомендуемую мощь;
- угрозу;
- требуемый тип специалиста;
- позиционные эффекты;
- подтверждённые составы;
- опасные комбинации;
- milestone ежедневной добычи.

Шаблон: `templates/expedition-level.md`.
