# Source Register

Единый реестр источников.

## Рекомендуемые ID

- `kefir-help-...` — официальная справка Kefir;
- `kefir-patch-...` — официальный changelog;
- `wiki-...` — LDoE Wiki;
- `reddit-YYYYMMDD-...` — практические обсуждения;
- `video-YYYYMMDD-...` — видеогайды;
- `user-shot-YYYYMMDD-...` — скриншоты пользователя.

Для каждого источника хранить:
- URL/идентификатор;
- дату публикации, если известна;
- дату проверки;
- что именно он подтверждает;
- ограничения источника.
