# Regional Tasks

Ежедневные/региональные задания, которые меняют обычную локацию.

Это отдельные записи, потому что одна и та же локация может требовать разной подготовки в зависимости от задания.

Примеры категорий:
- northern/
- islands/
- bog/

Для задания фиксировать:
- базовую локацию;
- точное название задания;
- цель;
- что меняется на карте;
- обязательный предмет/инструмент;
- дополнительные враги/босс;
- награду/региональное очко;
- подтверждённую дешёвую тактику.

Шаблон: `templates/regional-task.md`.
