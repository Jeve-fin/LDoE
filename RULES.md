# Rules of Truth

## 1. Иерархия источников

При конфликте данных использовать такой приоритет:

1. **Официальная игра / скрин пользователя** — фактическое состояние конкретной версии и аккаунта.
2. **Официальная справка Kefir / patch notes / официальные соцсети**.
3. **Актуальная Wiki**, если страница явно обновлена и согласуется с игрой.
4. **Свежие практические отчёты игроков** (Reddit, видео, форумы).
5. Старые гайды — только как исторический материал, не как текущий факт.

## 2. Статусы фактов

Каждый существенный факт должен иметь один из статусов:

- `official` — подтвержден официальным источником.
- `verified` — подтвержден несколькими актуальными независимыми источниками или скрином игры.
- `community` — подтвержден практикой сообщества, но не официально.
- `uncertain` — данные есть, но противоречивы/неполны.
- `obsolete` — старая механика, больше не актуальна.

## 3. Запреты

Нельзя:
- заполнять неизвестные значения предположениями;
- переносить старую механику на новую версию без проверки;
- считать английское название точным русским названием без проверки;
- указывать точные шансы/количества без источника;
- выдавать один пользовательский отчёт за установленный факт.

## 4. Версионность

У каждой записи должны быть:
- `checked_at` — дата последней проверки;
- `game_version` — версия, если она известна;
- `status`;
- список источников.

Если после крупного обновления данные не перепроверены, запись считать потенциально устаревшей.

## 5. Практические рекомендации

Отделять:
- **факт игры**;
- **подтверждённую тактику**;
- **нашу рекомендацию по экономии ресурсов**.

Рекомендация допустима только если ясно указано, на каких подтверждённых фактах она основана.
