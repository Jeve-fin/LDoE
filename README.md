# LDoE Knowledge Base

Персональная база знаний по **Last Day on Earth: Survival**.

Цель репозитория — хранить только проверяемые данные по игре в форме, удобной для быстрого ответа на практические вопросы:

- куда идти;
- что взять с собой;
- какие враги и боссы встретятся;
- какие механики действуют на локации;
- где добыть ресурс;
- как создать предмет;
- как пройти конкретный уровень экспедиции или региональное задание;
- что изменилось после обновлений.

## Основные принципы

1. Никакой отсебятины.
2. Любой изменяемый факт должен иметь источник и дату проверки.
3. Если данные расходятся — хранить оба варианта с пометкой статуса.
4. Старые механики не удалять бесследно: переносить в архив/историю.
5. Русские названия — основные для отображения; английские — для поиска источников.
6. Отдельно различать:
   - официальный факт;
   - подтверждённую игровую практику;
   - неподтверждённое сообщение сообщества.

## Навигация

- `CURRENT.md` — текущее состояние базы и актуальная версия игры.
- `RULES.md` — правила истины и приоритет источников.
- `SCHEMA.md` — единый формат записей.
- `INDEX.md` — общий индекс.
- `locations/` — постоянные и временные локации.
- `resources/` — ресурсы и материалы.
- `enemies/` — обычные противники.
- `bosses/` — боссы.
- `equipment/` — оружие, броня, инструменты, транспортное/спецоборудование.
- `expeditions/` — экспедиции Поселения по уровням.
- `regional-tasks/` — региональные ежедневные/сюжетные задания.
- `mechanics/` — механики игры.
- `updates/` — изменения по версиям.
- `sources/` — реестр источников.
- `templates/` — шаблоны новых записей.

## Статус

Архитектура базы создана. Содержимое будет добавляться по мере проверки фактов.
